# 这是什么站

本站基于开源电子书《高性价比人生指南》(HowToLiveBetter, 654 条建议 / 34 章, CC BY 4.0)做两件原书不做的事:

1. **按人生阶段重组** — 书按主题写, 人按阶段活。同一问题("现在最该做哪几件事"), 高中生和中年人的答案完全不同。5 个阶段手册全部人工策展, 不靠算法排序。
2. **提供坚持的工具** — 处境体检(16 题问卷, 全部在浏览器本地计算)与打卡与待办(每日/每周习惯 + 待办清单, 数据只存用户设备)。知识免费, 记忆与坚持的辅助收费(规划中)。

# 证据分级口径

- **A 级**: 有具体数字可查(荟萃分析/大型队列/官方统计)
- **B 级**: 有研究支持, 但缺少确切数字或样本较小
- **C 级**: 经验与通行做法, 缺少直接研究文献

每条建议页面均展示证据等级、原始论文/官方文件链接, 原书标注"数字待核实"的条目在站内保留该警示标记。
