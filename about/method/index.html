方法与证据

我们怎么筛、怎么排, 全部写在这里

健康、法律、金钱类的建议, 读者有权知道它从哪来、有多硬、我们加了什么自己的判断。这一页就是全部家底。

1. 内容来源

全部条目来自 eternity4719/HowToLiveBetter(CC BY 4.0):654 条建议、34 章、1566 条原始文献链接。我们不自行创作健康或法律结论, 只做重组、筛选与呈现; 内容疑义请以原书及其引用的原始文献为准。

2. 证据分级(原书定义)

  • A 级(429 条):来自荟萃分析、大型队列或随机对照试验, 可查到具体效果数字。
  • B 级(174 条):有研究支持, 但缺少确切数字, 或来自小样本、单项研究。
  • C 级(51 条):作者经验与通行做法, 缺少直接研究文献。

个别条目带争议标注(如「A(争议)」), 我们原样保留并显示。另有 3 条作者自标「待核实」, 条目页会显式提示。

3. 我们的加工(全部规则披露)

阶段映射

34 章被映射到五个人生阶段, 分「核心」「相关」两档权重(见各阶段页); 映射是编辑判断, 不是数据推导。

性价比排序(启发式, 非科学结论)

条目得分 = 收益量级(大 30 / 中 20 / 小 10)+ 证据强度(A 8 / B 4 / C 0)− 成本罚分(钱:零 0 / 少 2 / 多 8;时间:少 0 / 中 2 / 多 6;毅力:否 0 / 些 2 / 是 6)。阶段页在通用分上加章节权重(核心 +15 / 相关 +6)。

这条公式是为了把「大概率更值得先做」的东西排前面, 不是精确度量。收益大小与成本标签来自原书作者的判断; 四类收益(寿命/金钱/时间/人身自由)不可互相折算, 所以报告按类分组而非合并排名。

人工精选

每个阶段页置顶的「先做这 5 件」由编辑挑选, 标准:零成本或近零成本、主题各异、是该年龄段高频踩坑点。精选条目挂稳定编号, 原书修订后若条目被删, 构建会报错提醒人工复查。

4. 诚实的局限

  • 原书以中国大陆语境写作(医保、法条、热线), 其他司法与医保体系不适用。
  • 证据会过期:我们跟随上游仓库更新, 但上游之外的新研究不会自动出现。
  • 阶段是标签不是诊断:处境体检比年龄标签更细, 但仍是粗糙的过滤。
